## Method

The upstream Lane Runner (static/demos/runner.js, unchanged) is stepped headlessly at 1/120 s. One request is in flight at a time; while it is, the game advances by the measured HTTP round trip rounded up to whole steps, then the action is applied (upstream tools/record_run.mjs). Decisions are capped at 40 per game second, as in the browser. Each device is measured in its own server process with only that device loaded, one after the other, never concurrently.
